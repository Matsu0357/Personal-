# TikTok 収益化設計：中級英語リーディング

作成: 2026-10-26／対象: TikTok（先行）→ YouTubeショート・Instagramリールにも同じ動画を流用
前提: 中級（B1〜B2）・英文＋和訳スクロール・FishAudio（商用プラン）

---

## 1. 結論（最初に決めること）

1. **TikTok 用の動画は全部「1分以上」にする。** Creator Rewards Program（以下 CRP）は1分以上の動画にしか報酬が出ない。今の #01・#02（約50秒）は対象外の長さ。
2. **「文字が流れるだけ」に見えない作りにする。** CRP は「テキストオーバーレイのみ」「スライド」などをオリジナルとみなさない。→ 1回目の通し読みのあとに **「リピート練習」パート（音声 → あなたの番 🎤 の間）** と **「今日の表現」解説** を入れ、レッスンとして組み立てる。
3. **お金の柱は CRP だけにしない。** 学習系は再生単価より「自分の教材」「企業案件（英会話・学習アプリ）」のほうが大きい。フォロワー1,000人の時点から LINE などで見込み客を集めておく。

---

## 2. TikTok の収益化の条件（公式ヘルプで確認）

| 方法 | 主な条件 | この企画での使い方 |
| --- | --- | --- |
| **Creator Rewards Program** | 日本在住・**個人アカウント**・18歳以上・**フォロワー1万人**・**過去30日の視聴10万回**。対象動画は**1分以上のオリジナル**、参加承認**後**に投稿したもの、「おすすめ」で有効視聴（5秒以上）1,000回以上 | メインの再生報酬。1万人までの3つの数字を目標にする |
| LIVE ギフト | 18歳以上・LIVE 配信の資格（目安フォロワー1,000人） | 「一緒に音読 LIVE」（台本を読み合う・質問に答える） |
| TikTok Shop アフィリエイト | 18歳以上・フォロワー1,000人など | 英単語帳・音読教材・イヤホンなどの紹介（扱える商品を確認してから） |
| 動画ギフト・サブスクリプション | フォロワー1万人・過去30日の視聴10万回など | CRP と同じ時期に申し込む |
| TikTok One（企業案件） | フォロワー1万人など | 英会話スクール・英語アプリの案件。学習系と相性がよい ※案件動画は CRP の対象外 |

CRP の公式ヘルプで、オリジナルとみなされない例:
- デュエット・リミックス／他人の動画のコピー
- 少しだけ変えたコピー（速度・フィルター・固定テキスト）
- **ループ動画、写真だけ、テキストオーバーレイだけの動画**
- 著作権のある曲が1分以上流れる動画

報酬 = 有効視聴数 ÷ 1,000 × RPM（RPM は非公開。視聴時間・完了率などで動画ごとに変わる）。1再生あたりの単価は公式に出ていないので、承認後はダッシュボードの「推定報酬 ÷ 有効視聴数 × 1,000」で自分の RPM を計算して判断する。

### 守ること（アカウント）
- **個人アカウント**のまま運用する（ビジネスアカウントは CRP の対象外）
- 本名・生年月日などのアカウント情報は本物にする
- 視聴数・フォロワーを買わない。相互フォローの呼びかけもしない
- 承認前に投稿した動画は報酬の対象外 → **フォロワー1万人・視聴10万回に届いたらすぐ申し込む**

## 3. 動画の型（TikTok 版）

### 3-1. 構成（約80秒。#01 は82.7秒、#02 は80.1秒）

| 時間 | パート | 中身 | ねらい |
| --- | --- | --- | --- |
| 0〜3秒 | フック | 「これ、声に出して読める？」など（回ごとに変える） | 5秒以上見てもらう（有効視聴の条件） |
| 3〜50秒 | ① 通し読み | 今の型（英文＋和訳が流れ、読んでいる行をハイライト） | 聞きながら目で追う |
| 50〜70秒 | ② リピート練習 | 大事な3文を1文ずつ：音声 → 「あなたの番 🎤」の間（バーが減っていく） | 実際に声に出させる＝レッスンとしての中身。視聴時間も伸びる |
| 70〜78秒 | ③ 今日の表現 | 3つの表現と意味 | 保存したくなる |
| 最後 | お願い | 「読めたら🎤とコメント」「保存して明日もう一回」 | コメント・保存を増やす |

- **オリジナル性:** 英文は毎回自作、デザインと構成も自作、BGM も自作（著作権の曲は使わない）。リピート練習があるので「文字を重ねただけ」ではない
- **将来の強化案（任意）:** 自分の声で「今日のポイント」を10秒だけ話す／自分が実際に読んでいる手元・口元を入れる。人が出ると CRP の審査にも強く、ファンもつきやすい

### 3-2. AI の扱い
- 音声は FishAudio の AI 音声 → 投稿時に **「AI 生成コンテンツ」のラベルをオンにする**（一般的な読み上げ音声はラベル不要という解釈もあるが、あとから外せず、ラベルなしで見つかると表示制限の可能性があるため、付けておくのが安全）
- 実在の人物の声や見た目は使わない

### 3-3. 原稿のルール
- 自己啓発・日常・ストーリー中心。**事実を書くときは必ず出典を確認**（CRP は偽情報・誤情報が対象外）
- 約110語・11行・中級の語彙。速さ 0.8
- 「今日の表現」は毎回3つ。後で単語帳・教材にまとめられるよう、表で記録しておく

## 4. 投稿の設計

| 項目 | 設計 |
| --- | --- |
| 頻度 | **1日1本**（最初の30日は毎日。台本は週末に7本まとめて作る） |
| 時間 | 平日 20〜22時ごろから試す（通勤・夜の勉強時間を想定）。2週目以降、TikTok Studio の「フォロワーがアクティブな時間」に合わせて変える |
| シリーズ名 | 「中級英語リーディング #番号」で統一。プロフィールに固定（ピン留め）3本 |
| キャプション | 1行目はテーマの共感（例「断るのが苦手な人へ」）＋ #英語音読 #シャドーイング #英語学習 #英語リスニング など5個前後 |
| コメント | 🎤 のコメントには全部返す。テーマのリクエストを募集し、リクエストで作った回はコメント返信動画で出す |
| プロフィール | 「毎日1本、中級英語を声に出す。英検2級〜準1級／TOEIC 600〜800向け」＋リンク（使えるようになったら） |
| 流用 | 同じ動画を YouTube ショート・Instagram リールにも投稿（YouTube は3分まで投稿できる。60秒を超えても問題ない） |

## 5. 収益化までの段階

| 段階 | 目安 | やること | 見る数字 |
| --- | --- | --- | --- |
| 0. 準備 | 1週目 | 個人アカウント作成、プロフィール、最初の7本を用意 | — |
| 1. 型を見つける | 〜30本（1か月） | 毎日投稿。フック・テーマ・長さを少しずつ変えて比べる | **平均視聴時間・最後まで見た割合・保存数** |
| 2. フォロワー1,000人 | 2〜3か月目（目標） | LIVE「一緒に音読」を週1回／プロフィールのリンクから **LINE で「全文スクリプトPDF＋音声」を無料配布**して見込み客を集める／TikTok Shop アフィリエイトを試す | フォロワー増加数、LINE 登録数 |
| 3. フォロワー1万人＋30日10万回 | 半年以内（目標） | **CRP・サブスク・動画ギフトに申し込む**。TikTok One で企業案件を受ける | RPM、案件の単価 |
| 4. 自分の商品 | 1万人前後 | 音読教材（PDF＋MP3、30日分）を note や Brain などで販売、または月額の音読マガジン | 購入率 |

※ 期間は目安で、保証ではない。英語学習の競合調査では、大きなアカウント（フォロワー17万〜36万）が1本700万〜1,000万回再生を出しているので、型が当たれば伸びる余地は大きい。

### お金の柱の比べ方（イメージ）
- **CRP:** 再生数に比例。RPM は非公開なので、承認後に実数で判断
- **企業案件:** 英会話スクール・英語アプリは SNS 広告に積極的。フォロワー1万人を超えると話が来やすい
- **自分の教材:** 台本・表現の表・音声がすでに毎回たまるので、まとめるだけで商品になる（原価がほぼかからない）

## 6. 数字の見方（毎週）
`ShortVideo/07_analytics/reports/` に週1回まとめる。

| 数字 | 目標（最初の1か月） | 低いときに直すところ |
| --- | --- | --- |
| 5秒以上見た割合 | 60%以上 | フック（最初の1文と見た目） |
| 平均視聴時間 | 30秒以上 | テーマ・1回目の通し読みの長さ |
| 最後まで見た割合 | 15%以上 | 全体の長さ・リピート練習の数 |
| 保存数 ÷ 再生数 | 1%以上 | 今日の表現・「保存して明日も」のお願い |
| フォロワー増加 ÷ 再生数 | 0.5%以上 | シリーズ感・プロフィール |
