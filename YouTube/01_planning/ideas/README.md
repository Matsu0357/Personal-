## 横断して分かったこと
- 6件中3件（04・05・06）が「**Claudeで台本を書き、アニメーションもコードで作る**」タイプ。画像生成AIのコストがほぼゼロで、見た目も毎回そろう
- 登録者が少なくても、1本で数十万〜数百万回再生されている例が多い（おすすめに乗れば登録者数は関係ない）
- 共通点：**一つの型（タイトル・サムネイル・構成）を決めて、ネタだけ変えて繰り返す**
