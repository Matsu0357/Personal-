# 計画：「Then what?」型の日本語チャンネルをClaudeで作る

## コンセプト（仮）
- 仮のチャンネル名：**「それから、どうなる？」**／シリーズの決まり文句は「〇〇したら、それからどうなる？」
- 主人公：オリジナルのdoodleマスコット（元チャンネルの猫耳キャラは真似しない。形・色・名前は独自に）
- 1本の長さ：8〜12分の長尺＋切り抜きのショート2本
- 頻度：最初は週1本（量産型の規定への対策として、量より質を優先）

## 担当の分け方
| 工程 | 担当 | ツール／方法 |
| --- | --- | --- |
| 1. ネタ出し・リサーチ | Claude | Web検索で科学的な根拠を集め、出典を残す |
| 2. 台本 | Claude → 自分で直す | 日本語のナレーションは約300〜350字で1分 → 10分で3,000〜3,500字 |
| 3. シーン分け | Claude | 台本を1シーン5〜10秒に分けたJSON（下にひな形） |
| 4. 画像 | 画像生成AI | ClaudeはPNGなどの画像を生成できない → 下の「画像の選択肢」 |
| 5. ナレーション | 音声合成 | VOICEVOX（無料・クレジットの表記が必要）／ElevenLabs（日本語可・有料）など |
| 6. 動画の組み立て | Claude Codeが書いたスクリプト | Remotion（React）またはPython＋ffmpeg。ズーム・パン、字幕、BGMを自動で付ける |
| 7. サムネイル | 画像生成AI＋Claude | 大きな年号＋主人公。文字入れはHTMLをPNGにする方法で自動化できる |
| 8. タイトル・説明文・タグ | Claude | タイトル案を10個出して選ぶ |
| 9. 最終チェック | **自分** | 事実の確認、聞きやすさ、絵と話のずれ |

### 画像の選択肢
- **A. Gemini（推奨）**：すでにある `gemini-illustration-batch` スキルで、プロンプトのファイルから一括生成できる。マスコットの参照画像を毎回付けて、見た目をそろえる。
- **B. ClaudeがSVGで描く**：キャラクターの見た目が完全にそろい、無料で、パーツ単位で動かせる。絵はシンプルになる。マスコットだけSVG、背景はGeminiという組み合わせも可能。
- **C. ChatGPTの画像生成など**：Aの代わりに。

## ネタ案（最初の10本）
1. 宇宙の終わりまで生きたら、何が見える？
2. 100万年後に目覚めたら、それからどうなる？
3. 江戸時代にタイムスリップしたら、生き残れる？（日本向けにローカライズ）
4. ビッグバンの瞬間に立ち会ったら？
5. 地球の自転が止まったら、それからどうなる？
6. 太陽が消えたら、最後の8分20秒に何が起きる？
7. 1億年前の日本に行ったら、何がいる？（日本向け）
8. ブラックホールに落ちたら、何が見える？
9. 月が地球に近づいてきたら？
10. 人類がいなくなった1万年後の東京は？（日本向け）

→ 3・7・10のように **日本の土地や歴史に置き換えたネタ** が、英語版をただ翻訳したものとの差別化になる。

## 注意点
- **量産型のコンテンツ**：一枚絵＋AI音声だけで解説の少ない動画は収益化NGになりやすい。台本の独自性（日本向けの切り口、正確な科学考証）と、絵の動き・演出で人の手による付加価値を出す。
- **真似しすぎない**：元チャンネルのキャラクター、サムネイルのデザイン、台本をそのまま使わない。真似するのは「型」（二人称×時間軸の思考実験）だけ。
- **事実の確認**：科学の題材は誤りが命取り。台本の主張ごとに出典を付け、公開前に自分で確認する。
- **AI利用の開示**：YouTubeでは、本物と見間違うような合成コンテンツには開示が必要。doodle絵は通常は対象外と考えられるが、公開時に設定を確認する。
- **音声のライセンス**：VOICEVOXはキャラクターごとに利用規約とクレジットの表記が違う。商用利用（収益化）が可能かを確認する。
