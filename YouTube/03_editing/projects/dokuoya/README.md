# 試作4本目：大人になっても消えない。毒親育ちの人がやりがちな8つのこと（Inspire and Thrive 型）

参考: `../../../01_planning/research/inspire-and-thrive.md`／前作 `../gaslighting/`（同じ仕組み）

## コンセプト
- 型：黒地・白い棒人間・キーワードだけ赤の「8つの〇〇」解説
- 結末を先に決めた：**8つのクセは欠点ではなく、子どもの頃のあなたが、その家で生き延びるために身につけた方法。いまはもう手放していい**。親を責める動画ではなく、自分を責めなくていいと伝える動画
- 相談窓口の案内は入れない（前作と同じ方針）
- 長さ：5分49秒

## 日本向けにした点
- 冒頭は日本の家庭でよく聞くことば：「誰のおかげで、ごはんが食べられると思ってるの」「お姉ちゃんなんだから、がまんしなさい」「あなたのためを思って」
- 「親を悪く言うなんて」「親孝行しなさい」という空気で、つらかったと言いにくいことに触れる
- 8つ：①「ちゃんとしなきゃ」が抜けない（90点で「あと10点は？」）②人のため息にビクッとする（職場で）③ほめられると居心地が悪い（「いえいえ、全然」）④人に頼るのがこわい（「迷惑をかけちゃいけない」）⑤自分の「好き」が分からない ⑥休むと罪悪感（「だらだらして」）⑦親からのLINEで体がこわばる（「母」の通知、お盆・正月）⑧親を好きになれない自分を責める（「育ててもらったのに」）

## 正確さのために
- 「毒親」はスーザン・フォワード『毒になる親』がもとになった言葉で、医学的な診断名ではないと明言
- 「これは診断ではない」と明言。「当てはまったら毒親育ち」とは言わない
- 「親にも事情があったのかもしれない。それでも、あなたが傷ついたことは本当のこと」と、親を一方的に断罪しない
