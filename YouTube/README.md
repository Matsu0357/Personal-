# YouTube

YouTube動画制作・チャンネル運営用のフォルダ構成です。

| フォルダ | 用途 |
| --- | --- |
| `01_planning/ideas` | 動画ネタ・アイデアメモ |
| `01_planning/research` | リサーチ資料・競合調査 |
| `01_planning/scripts` | 台本・構成案 |
| `02_assets/footage` | 撮影素材・録画データ |
| `02_assets/audio/bgm` | BGM |
| `02_assets/audio/sfx` | 効果音 |
| `02_assets/audio/voiceover` | ナレーション・音声収録 |
| `02_assets/images` | 画像素材 |
| `02_assets/fonts` | フォント |
| `03_editing/projects` | 編集ソフトのプロジェクトファイル |
| `03_editing/subtitles` | 字幕ファイル（.srt など） |
| `04_thumbnails/drafts` | サムネイル案 |
| `04_thumbnails/final` | 確定サムネイル |
| `05_exports/main` | 書き出し済みの本編動画 |
| `05_exports/shorts` | 書き出し済みのショート動画 |
| `06_publishing/metadata` | タイトル・説明文・タグ |
| `06_publishing/schedule` | 投稿スケジュール |
| `07_analytics/reports` | アナリティクス・振り返り |
| `08_channel/branding` | ロゴ・バナー・アイコン |
| `08_channel/templates` | 台本・サムネ・説明文のテンプレート |
| `99_archive` | 公開済み・不要になったデータの保管 |

> 空フォルダをGitで管理するため、各フォルダに `.gitkeep` を置いています。
