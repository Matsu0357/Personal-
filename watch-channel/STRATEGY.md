# 「1分でわかる時計史」TikTok 収益化戦略（2026年10月〜12月）

## ゴール

**2026年12月31日までに、TikTok の Creator Rewards Program（収益化プログラム）の条件を満たして申請する。**

### Creator Rewards の条件（2026年10月時点で調べた内容）

| 条件 | 内容 |
|---|---|
| 年齢 | 18歳以上 |
| アカウント | 個人アカウント（ビジネスアカウントは対象外） |
| フォロワー | 10,000人以上 |
| 再生数 | 直近30日で100,000回以上（主に「おすすめ」フィードからの再生） |
| 動画の長さ | **1分を超える**オリジナル動画だけが報酬の対象 |
| 報酬の対象になる動画 | 1本あたり1,000回以上の有効な視聴（5秒以上） |

- 日本は対象国に含まれています。ただし条件は変わることがあるので、**アプリの「TikTok Studio」→「収益化」で、表示と条件を必ず確認**してください。
- このチャンネルの動画は、**すべて61秒以上**で作っています（63〜78秒）。

### 見通し（正直に）

- 残りは約9週間です。条件のうち、**フォロワー1万人がいちばん高い壁**です。
- 教育系のショート動画は、1本でも10万再生を超える動画が出ると、フォロワーが一気に増える傾向があります。ただし、伸びるかどうかは保証できません。
- そこで「毎日投稿で試行回数を増やす」「伸びたテーマに寄せる」「収益化の別ルートも並行する」の3本柱でいきます。

## 3本柱

### 1. 毎日投稿（試行回数を最大化）

- **1日1本、19:00〜21:00に投稿**します。時間はできるだけそろえます。
- 最初の30日分（30本）は制作済みです。最終的な投稿日は、アカウント側の準備ができ次第決めてください。下のカレンダーは10/28開始の場合の例です。
- 2週目以降、反応のよかったテーマの続編を追加で作ります。

### 2. 伸びる型を見つけて寄せる

各動画は同じ型で作っています。
- **最初の2秒で「数字」か「問い」**を出します（例：「腕時計1本に約20億円」「3階の窓から時計を落とし続けた男」）。
- キャラクター（時計職人くん）、シリーズ名、配色を統一し、「あのシリーズだ」と覚えてもらいます。
- 最後に**コメントを促す質問**を入れます（コメント数は「おすすめ」に載るための重要な指標と言われます）。

1週間ごとに TikTok Studio の数字を見て、次の作戦を決めます。

| 見る指標 | 目安 | 悪いときの打ち手 |
|---|---|---|
| 平均視聴時間・視聴維持率 | 最初の3秒で離脱が多いか | 冒頭のセリフと画面を強くする |
| 完全視聴率 | 30%以上 | 中だるみするカットを削る |
| コメント数 | 再生の0.5%以上 | 質問をもっと答えやすくする |
| フォロー率 | 再生の1%以上 | シリーズ感を強くし、「次回」の予告を入れる |

テーマ別の仮説：
- **お金・数字系**（20億円、45万円）と、**日本ブランド系**（G-SHOCK、セイコー）が伸びやすいと予想しています。
- 伸びたテーマは、**同じ型で2〜3本**続編を作ります（例：ロレックスが伸びたら「サブマリーナー」「デイトナ誕生」など）。

### 3. 収益化の別ルートも並行する

Creator Rewards に間に合わない場合でも、収入を作れるようにしておきます。
- **YouTube ショート、Instagram リール**にも同じ動画を投稿します（ロゴの透かしなしのファイルを使います）。
- **TikTok LIVE のギフト**：Creator Rewards より条件が低めです（条件は地域によって違うので、アプリで確認してください）。
- **TikTok Shop のアフィリエイト**：時計ベルトや時計ケースなどを紹介できます。
- フォロワーが増えてきたら、時計店や時計メディアの **PR案件**も狙えます。

## 運用ルール

- **プロフィール**：「1分でわかる時計史｜時計ブランドの歴史と雑学を毎日投稿」のように、何のアカウントかひと目でわかる文にします。
- **AI表示**：ナレーションはAI音声なので、投稿時に「AI生成コンテンツ」のラベルをオンにしておくのが安全です。
- **ハッシュタグ**：キャプション（`videos/*.txt`）に3〜8個入れてあります。検索されやすいブランド名を必ず入れています。
- **公式画像は使っていません**。時計の絵は、すべてロゴのない自作イラストです。
- **事実確認**：各台本ファイル（`episodes/epNN_*.py`）の冒頭に「確認ポイント」を書いてあります。投稿前に、年号や金額だけでも一度確認してください。
- **コメントへの返信**：最初の1時間は、できるだけ返信します。質問が来たら「動画で返信」機能を使うと、次のネタにもなります。

## 制作の仕組み

```
watch-channel/
  episodes/epNN_*.py   台本（カット・字幕・読み・キャプション・確認ポイント）
  videos/epNN_*.mp4    完成動画（投稿用）
  videos/epNN_*.txt    投稿用キャプション
  engine.py            台本 → 画像・ナレーション・SE・BGM → mp4
  scenes.py / props.py 背景と小道具（時計の絵）
  build_all.py         まとめてビルド（python3 build_all.py ep05 のように個別にも可）
```
