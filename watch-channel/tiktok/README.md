# TikTok アカウント「1分でわかる時計史」セットアップ

## プロフィール

| 項目 | 入れる内容 |
|---|---|
| 名前（表示名・30文字まで） | `1分でわかる時計史｜時計職人くん` |
| ユーザー名 | 作成済みのものでOK（未定なら `tokeishi_1min`。変更は30日に1回まで） |
| 自己紹介（80文字まで） | 下の文をそのまま貼り付け |
| プロフィール写真 | `icon.png`（720×720。丸く切り抜かれる前提で顔を中央に配置済み） |

自己紹介：

```
時計ブランドの誕生秘話と雑学を1分で⌚
毎日20時に投稿｜ロレックス・オメガ・セイコー…
あなたの時計の話もコメントで教えてね
```

## アカウント設定（収益化の条件に関わるもの）

- **個人アカウントのままにする。** ビジネスアカウントに切り替えると Creator Rewards の対象外になります。
- **公開アカウントにする**（「非公開アカウント」はオフ）。
- 生年月日が18歳以上で登録されていることを確認する。
- 名前やユーザー名に、ブランド名や公式と誤解される言葉を入れない。

## 予約投稿

- 一覧は `schedule.csv`（Excel で開けます）。10/28(水)〜11/26(木)、毎日20:00、30本です。
- パソコンのブラウザで **TikTok Studio**（https://www.tiktok.com/tiktokstudio/upload）を開いて予約します。スマホアプリには予約機能がありません。
- 1本ずつ、次の手順で入れます。
  1. 動画ファイルをアップロードする
  2. 説明欄に「キャプション」列の文を貼る（ハッシュタグ込み）
  3. 「AI生成コンテンツ」のラベルをオンにする（詳細設定の中にあります）
  4. 「スケジュール」を選び、「投稿日」と「時刻」を入れる
  5. 予約したら、`schedule.csv` の「状態」列に「予約済み」と書く
- 何日先まで予約できるかには上限があります。画面で選べる範囲まで予約し、残りは数日おきに足していきます。
- 作ったばかりのアカウントで一度に大量に予約すると、機械的な操作と判定されるおそれがあります。**最初の3〜5本は様子を見ながら予約**し、問題がなければ残りを入れてください。

日付や時刻を変えたいときは、`python3 make_schedule.py 2026-10-29 19:30` のように実行すると一覧を作り直せます。
