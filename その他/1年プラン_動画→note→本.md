# 1年プラン：SNS動画 → note → 有料記事 → Kindle本

作成日: 2026-10-27（同日更新：集客をTikTok・Instagram・Xに変更／Kindleは書き下ろしに決定）
期間: 2026年11月〜2027年10月（6ヶ月目に見直し）
関連: [Kindle本_企画書_ガスライティング毒親.md](./Kindle本_企画書_ガスライティング毒親.md)

## 決まったこと
- **集客はTikTok・Instagram・X（Twitter）**
- **Kindle本は書き下ろし**（noteの記事は使い回さない）
- テーマ: ガスライティング・毒親（チャンネルで試作済みの内容）

## 全体の流れ

```
TikTok・Instagram・X … 無料で知ってもらう（集客）
   ↓ プロフィールのリンク
note 無料記事 … 「もっと知りたい人」向けの補足
   ↓ 記事の最後で案内
note 有料記事（たまに）… すぐ使える道具
   ↓ 反応で「本に何を書くか」を決める
Kindle本（書き下ろし）… 全部をつなげて体系化した完成版
   ↓ 本の中でSNS・noteを紹介 → また最初に戻る
```

## SNSそれぞれの役割

| SNS | 役割 | 出すもの | リンクの置き場所 |
|---|---|---|---|
| **TikTok** | 一番新しい人に見つけてもらう | 縦型ショート動画（試作済みのショート版の形式がそのまま使える） | プロフィールのリンク（下の注意を参照） |
| **Instagram** | 保存してもらう・信頼してもらう | ①リール（TikTokと同じ動画）②**カルーセル投稿**（「8つのサイン」を1枚ずつ画像に。保存されやすい）③ストーリーズ | プロフィールのリンク、ストーリーズのリンクスタンプ |
| **X** | 毎日の接点・noteへの導線 | 一言の気づき、言い回し、短いスレッド。noteはX経由で読まれやすい | **投稿本文ではなく、自分の投稿へのリプ欄**にnoteのリンク |

### SNSごとの注意
- **TikTok**: 個人アカウントは**フォロワー1,000人になるまでプロフィールにクリックできるリンクを置けない**。**ビジネスアカウントにすれば最初から置ける**（ただしビジネスアカウントは使えるBGMが限られる。自作のBGMなら問題なし）
- **Instagram**: TikTokからダウンロードした動画には**TikTokのロゴ（透かし）が入る**ので、リールには**元の動画ファイル**を投稿する
- **X**: 本文に外部リンクを入れると表示されにくくなる傾向がある（調査あり）。リンクはリプ欄かプロフィールに置く
- **共通**: すべての動画に「※医学的な診断を目的としたものではありません」を入れる（今の動画と同じルール）

## それぞれの中身（ここを混ぜない）

| 場所 | 役割 | 中身の例 | 値段 |
|---|---|---|---|
| TikTok・リール | 見つけてもらう | 「毒親育ちの8つのクセ、いくつ当てはまる？」 | 無料 |
| Instagramカルーセル | 保存してもらう | 「ガスライティングの8つのサイン」を1枚ずつ | 無料 |
| X | 毎日思い出してもらう | 「『気にしすぎ』と言われたら、まず記録を。」のような一言 | 無料 |
| note 無料記事 | 動画の続き・補足 | 出典の解説、動画で言えなかった場面、コメントへの答え | 無料 |
| note 有料記事 | すぐ使える道具 | 言い回し集、チェックリスト、書き込みシート | 300〜500円 |
| Kindle本 | 全部をつなげた完成版（**書き下ろし**） | 仕組み＋実用＋練習を1冊に | 電子250〜500円／紙1,000円台 |

### Kindle本を書き下ろしにする理由
- 本を **KDPセレクト（読み放題）** に入れると、**その本の電子版の中身を他で配信できない**（サンプルとして最大10%程度まで）
- noteの記事をそのまま本にすると規約違反になるおそれがあるので、**本は新しく書く**
- noteは「単発の場面・質問への答え」、本は「体系（仕組み→実用→練習）」と役割を分ける
- 細かい条件は、出版前にKDP公式ヘルプで確認

### note の手数料（公式ヘルプより）
- 決済手数料: クレジットカード5%、PayPay 7%、PayPal 6.5%、携帯キャリア15%
- プラットフォーム利用料: 上の残りから10%（有料記事・メンバーシップ）
- 振込手数料: 1回270円
- 例: 500円の記事がカードで売れる → 約427円が手元に（振込手数料は別）

## 月ごとのプラン

### 第1期：土台づくり（1〜2ヶ月目 / 2026年11〜12月）
**目標: 3つのSNSで出し続ける習慣と、noteへの道をつくる**
- [ ] アカウント開設: TikTok（**ビジネスアカウント**）、Instagram、X、note。名前とアイコンをそろえる
- [ ] 各プロフィールにnoteのリンク
- [ ] 試作済みの2本（ガスライティング・毒親）のショート版を、本番の音声にして公開
- [ ] 1本の動画を「TikTok・リール・Xの動画投稿」に使い回す
- [ ] 「8つのサイン」「8つのクセ」をInstagramのカルーセル投稿にする
- [ ] Xは毎日1〜3投稿（動画の中の一言を切り出す）
- [ ] 動画のテーマごとに、noteの無料補足記事を1本
- [ ] 投稿ペースの目安: ショート動画 週3〜5本／カルーセル 週1〜2本／X 毎日
- [ ] 毎週、再生数・保存数・コメント・noteへのアクセスをメモする

### 第2期：反応を見る（3〜4ヶ月目 / 2027年1〜2月）
**目標: どの話が一番求められているかを知る**
- [ ] コメント・DM・Xの反応で多かった悩みを集める（例: 「親からのLINEにどう返せば」）
- [ ] その悩みに答えるショート動画とnote無料記事を作る
- [ ] **最初の有料記事**を1本（例: 「親からのLINE・帰省の連絡への返し方 言い回し集」300〜500円）
- [ ] 本の核になる一言の候補（「もう、顔色を見なくていい」など）を、動画の最後やXで試す
- [ ] どのSNSからnoteに一番来ているかを確認

### 第3期：6ヶ月目の見直し（5〜6ヶ月目 / 2027年3〜4月）
**目標: 力を入れるSNSと本のテーマを決める**
- [ ] 有料記事を月1本ペースで出す
- [ ] 6ヶ月の振り返り（下の「見直しで見ること」）
- [ ] 反応の弱いSNSは投稿を減らし、強いSNSに集中する
- [ ] 本のタイトルと核になる一言を決める
- [ ] 本の目次を確定（反応が良かった話を厚くする）

### 第4期：本を書く（7〜9ヶ月目 / 2027年5〜7月）
**目標: SNSとnoteを続けながら、本を書き下ろす**
- [ ] 有料記事は月1本を継続（本と違うテーマ・単発の道具に限る）
- [ ] 本を書き下ろす（3〜5万字、月1〜1.5万字ペース）
- [ ] SNSでも本の内容に近いテーマを出して、反応を確かめる
- [ ] できれば公認心理師などの監修を相談

### 第5期：出版準備（10〜11ヶ月目 / 2027年8〜9月）
**目標: 本を出す準備と、出版前の盛り上げ**
- [ ] 表紙・説明文・キーワードを作る（他の作者名や作品名は使わない）
- [ ] 文章や画像の生成にAIを使ったなら、KDPへの申告を準備
- [ ] 「本を書いています」と各SNS・noteで予告。目次の一部を見せて反応を見る
- [ ] 出版日を告知

### 第6期：出版（12ヶ月目 / 2027年10月）
**目標: 出してすぐにレビューとランキングを取る**
- [ ] 電子書籍（KDPセレクト）＋紙の本を同時に出版
- [ ] 出版直後に無料キャンペーン（90日ごとに最大5日）。各SNSで告知
- [ ] 「本の中から1つ紹介します」ショート動画・カルーセルを作る
- [ ] 全SNSとnoteのプロフィールに本のリンク
- [ ] 本の最後で、SNSとnoteを紹介

## 6ヶ月目の見直しで見ること
数字の目標は、最初の2ヶ月の実績を見てから決める（今は決めない）。

| 見るもの | 分かること |
|---|---|
| SNSごとのフォロワー・再生数・保存数 | どのSNSに力を入れるべきか |
| どのSNSからnoteに来ているか | 一番お客さんにつながるSNS |
| コメント・DMで多い悩み | 本で厚く書くべき章 |
| noteのフォロワー・有料記事の販売数 | お金を払ってでも欲しい内容は何か |
| どの「一言」の反応が良かったか | 本のタイトル |

→ 反応が弱ければ、テーマの切り口や投稿ペースを見直す

## 補足
- YouTubeは無理に並行しない。余裕があれば、同じショート動画をYouTubeショートにも出す（手間はほぼ増えない）
- 1冊目が出たら、「職場編」「夫婦・恋人編」などシリーズ化を検討
