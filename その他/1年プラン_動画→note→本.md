# 1年プラン：動画 → note → 有料記事 → Kindle本

作成日: 2026-10-27
期間: 2026年11月〜2027年10月（6ヶ月目に見直し）
関連: [Kindle本_企画書_ガスライティング毒親.md](./Kindle本_企画書_ガスライティング毒親.md)

## 全体の流れ

```
YouTube（ショート・長尺）… 無料で知ってもらう
   ↓ 説明欄・固定コメントからリンク
note 無料記事 … 「もっと知りたい人」向けの補足
   ↓ 記事の最後で案内
note 有料記事（たまに）… 一番役に立つ実用部分
   ↓ 反応で「本に何を書くか」を決める
Kindle本 … 全部をまとめて体系化した完成版
   ↓ 本の中で動画・noteを紹介 → また最初に戻る
```

## それぞれの役割（ここを混ぜない）

| 場所 | 役割 | 中身の例 | 値段 |
|---|---|---|---|
| ショート | 見つけてもらう | 「8つのクセ、いくつ当てはまる？」 | 無料 |
| 長尺動画 | 信頼してもらう | 「〇つのサイン」解説 | 無料 |
| note 無料記事 | 動画の続き・補足 | 出典の解説、動画で言えなかった場面、視聴者の質問への答え | 無料 |
| note 有料記事 | すぐ使える道具 | 言い回し集、チェックリスト、書き込みシート | 300〜500円 |
| Kindle本 | 全部をつなげた完成版 | 仕組み＋実用＋練習を1冊に | 電子250〜500円／紙1,000円台 |

### ⚠ 大事：noteと本の中身を同じにしない
- 本を **KDPセレクト（読み放題）** に入れると、**その本の電子版の中身を他で配信できない**（サンプルとして最大10%程度まで）
- noteに載せた記事をそのまま本にすると、規約違反になるおそれがある
- **ルール**: 本は「書き下ろし」にする。noteは「単発の場面・質問への答え」、本は「体系（仕組み→実用→練習）」と役割を分ける
- 10%の数え方などの細かい条件は、出版前にKDP公式ヘルプで確認

### note の手数料（公式ヘルプより）
- 決済手数料: クレジットカード5%、PayPay 7%、PayPal 6.5%、携帯キャリア15%
- プラットフォーム利用料: 上の残りから10%（有料記事・メンバーシップ）
- 振込手数料: 1回270円
- 例: 500円の記事がカードで売れる → 約427円が手元に（振込手数料は別）

## 月ごとのプラン

### 第1期：土台づくり（1〜2ヶ月目 / 2026年11〜12月）
**目標: 動画を出し続ける習慣と、noteへの道をつくる**
- [ ] 試作済みの2本（ガスライティング・毒親）を本番の音声にして公開。ショート版も公開
- [ ] 投稿ペースを決める（目安: 長尺 週1本、ショート 週2〜3本）
- [ ] noteアカウント開設。プロフィールにチャンネルへのリンク
- [ ] 動画1本ごとに、noteの無料補足記事を1本（「動画で紹介した〇〇を、もう少し詳しく」）
- [ ] 動画の説明欄の一番上・固定コメントにnoteのリンク
- [ ] 毎週、再生数・コメント・noteへのクリック数をメモする

### 第2期：反応を見る（3〜4ヶ月目 / 2027年1〜2月）
**目標: どの話が一番求められているかを知る**
- [ ] コメントで多かった悩みを集める（例: 「親からのLINEにどう返せば」）
- [ ] その悩みに答える動画とnote無料記事を作る
- [ ] **最初の有料記事**を1本（例: 「親からのLINE・帰省の連絡への返し方 言い回し集」300〜500円）
- [ ] 本の核になる一言の候補（「もう、顔色を見なくていい」など）を、ショートの最後で試す

### 第3期：6ヶ月目の見直し（5〜6ヶ月目 / 2027年3〜4月）
**目標: 続け方と本のテーマを決める**
- [ ] 有料記事を月1本ペースで出す
- [ ] 6ヶ月の振り返り（下の「見直しで見ること」）
- [ ] 本のタイトルと核になる一言を決める
- [ ] 本の目次を確定（反応が良かった話を厚くする）

### 第4期：本を書く（7〜9ヶ月目 / 2027年5〜7月）
**目標: 動画とnoteを続けながら、本を書き下ろす**
- [ ] 有料記事は月1本を継続（本と違うテーマ・単発の道具に限る）
- [ ] 本を書く（3〜5万字、月1〜1.5万字ペース）
- [ ] 動画でも本の内容に近いテーマを出して、反応を確かめる
- [ ] できれば公認心理師などの監修を相談

### 第5期：出版準備（10〜11ヶ月目 / 2027年8〜9月）
**目標: 本を出す準備と、出版前の盛り上げ**
- [ ] 表紙・説明文・キーワードを作る（他の作者名や作品名は使わない）
- [ ] 文章や画像の生成にAIを使ったなら、KDPへの申告を準備
- [ ] 「本を書いています」と動画・noteで予告。目次の一部を見せて反応を見る
- [ ] noteの読者に、出版日を告知

### 第6期：出版（12ヶ月目 / 2027年10月）
**目標: 出してすぐにレビューとランキングを取る**
- [ ] 電子書籍（KDPセレクト）＋紙の本を同時に出版
- [ ] 出版直後に無料キャンペーン（90日ごとに最大5日）
- [ ] 「本の第3部から1つ紹介します」ショートを作る
- [ ] 全部の動画の説明欄・固定コメント・noteのプロフィールに本のリンク
- [ ] 本の最後で、チャンネルとnoteを紹介

## 6ヶ月目の見直しで見ること
数字の目標は、最初の2ヶ月の実績を見てから決める（今は決めない）。

| 見るもの | 分かること |
|---|---|
| 再生数・登録者数が増えているか | 集客が回っているか |
| コメントで多い悩み | 本で厚く書くべき章 |
| noteへのクリック数・フォロワー | 「もっと知りたい人」がどれくらいいるか |
| 有料記事が何本売れたか | お金を払ってでも欲しい内容は何か |
| どの「一言」の反応が良かったか | 本のタイトル |

→ 反応が弱ければ、テーマ（ガスライティング・毒親）の切り口を変えるか、投稿ペースを見直す

## 補足
- YouTubeの収益化（YouTubeパートナープログラム）の条件に届いたら、広告収入もプラスになる
- 1冊目が出たら、「職場編」「夫婦・恋人編」などシリーズ化を検討
