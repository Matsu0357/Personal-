作成日: 2026-10-27
関連:
- 調査メモ: [Kindle出版_心理系ジャンル調査メモ.md](./Kindle出版_心理系ジャンル調査メモ.md)

## 方針
- 中身: チャンネルの「ガスライティング」「毒親」をまとめて、**動画より一段深い（アドバンスドな）本**にする
- Let Them Theoryから真似するのは**売り方と広げ方だけ**。内容は真似しない

---

## Let Them Theoryの売り方（調べて分かったこと）

| やったこと | 中身 |
|---|---|
| ① 60秒の縦動画から始まった | メル・ロビンズがInstagramに自撮りの短い動画を投稿 → 6,300万回再生とも言われる |
| ② 反応が良かったものを長尺に | その動画を流すところから始まるポッドキャスト回を作った（2023年5月） |
| ③ 長尺が本になった | 1年半後（2024年12月）に同じテーマで本を出版 |
| ④ 全形式で同時に売った | 紙の本・電子書籍・オーディオブックを同時に展開。9ヶ月で700万部 |
| ⑤ 考え方を短い一言にした | 「Let Them（放っておこう）」の2語。覚えやすく、人に言いたくなる |
| ⑥ 「バズ」より「役に立つ」 | 本人いわく「Vital, not viral」「特定の人たちにとってばかばかしいほど役に立つものを作る」 |

### 自分のチャンネルに置き換えると

| Let Them Theory | 自分の場合 |
|---|---|
| 60秒の縦動画 | すでにある縦型ショート版（毒親は1分52秒） |
| ポッドキャスト | YouTubeの長尺動画（5〜6分） |
| 本 | このKindle本 |
| 「Let Them」の一言 | **本の核になる一言を決める**（下記） |
| オーディオブック | 動画のナレーションの仕組みがあるので、音声版も作りやすい（日本で個人が音声版を出す方法は要確認） |

→ **すでに「ショート → 長尺」までの流れはできている。足りないのは「一言」と「本」だけ。**

---

## 本の核になる一言（案）
ガスライティングと毒親の共通点: **「他人が、あなたの気持ちや記憶の正しさを決めてくる」関係**。毒親の動画の結論「生き延びるための方法だった。もう手放していい」とつながる言葉にする。

1. **「あなたの記憶は、あなたのもの」**（ガスライティング寄り。覚えやすい）
2. **「もう、顔色を見なくていい」**（両方の共通点。日本の日常語）
3. **「それは、あなたのせいじゃなかった」**（毒親寄り。やさしい）

→ ショート動画のタイトルや最後の一言として何パターンか試して、反応が良いものを本のタイトルにする

---

## 本の構成案（動画より一段深く）

**仮タイトル**: 『もう、顔色を見なくていい ― ガスライティングと毒親から、自分の気持ちを取り戻す本』

| 部 | 内容 | 動画との違い（アドバンスド部分） |
|---|---|---|
| はじめに | この本は診断ではない。親や相手を責める本ではない | ― |
| 第1部 気づく | ガスライティングの8つのサイン／毒親育ちの8つのクセ | 動画の内容を土台に、それぞれ具体的な場面（職場・夫婦・実家・LINE）を増やす |
| 第2部 なぜ起きるのか | 2つは同じ仕組み（力の差＋くり返し＋「あなたが悪い」）／なぜやさしい人ほど気づきにくいか | 動画では言えなかった仕組みの説明。研究（Sweet 2019、フォワード『毒になる親』など）に沿う |
| 第3部 距離をとる | 記録の残し方／「言った・言わない」への返し方／親からのLINE・帰省との付き合い方／境界線の引き方 | **そのまま使える言い回し・チェックリスト・書き込みシート**（動画にはない実用部分） |
| 第4部 取り戻す | 自分の「好き」を思い出す／休むことの罪悪感をへらす／頼れる人をつくる | 毎日できる小さな練習 |
| おわりに | 「それは生き延びるための方法だった。もう手放していい」 | ― |

- 文字数の目安: 3〜5万字（読み放題で最後まで読まれやすい長さ）
- 動画と同じルールを守る: 「診断ではない」と明記、出典を書く、相手を一方的に断罪しない。できれば公認心理師などの監修
- 文章や画像の生成にAIを使ったら、出版時にKDPへ申告する

## 出版までの流れ（Let Them Theory式）

1. **テーマのテスト（今〜）**
   - ガスライティング・毒親まわりのショートと長尺を何本か追加（例: 「ガスライティングされた人の回復の8ステップ」「毒親からのLINEへの返し方」）
   - 再生数・コメントが多かった話を、本の章として厚くする
   - 核の一言を、ショートの最後で何パターンか試す
2. **本を書く**
   - 動画の台本を土台に、第2部（仕組み）と第3部（実用）を書き足す
   - 視聴者コメントを使うなら、個人が分からないように書き換える
3. **出版**
   - 電子書籍（Kindle Unlimited対象、KDPセレクト）＋ペーパーバック（KDPの紙の本）を同時に出す
   - 値段: 電子は250〜500円、紙は1,000円台
   - KDPセレクトの無料キャンペーン（90日ごとに最大5日）を出版直後に使い、最初のレビューとランキングを取る
4. **動画で宣伝**
   - 動画の説明欄の一番上・固定コメントに本のリンク
   - 「本の第3部から1つ紹介します」というショートを作る
   - 長尺の最後に「もっと詳しくは本で」と一言
5. **次の本へ**
   - 反応が良ければ「職場編」「夫婦・恋人編」などシリーズにする
