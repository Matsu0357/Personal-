# 日本に輸入できそうな「診断」と収益化アイデア

作成日: 2026-10-27

## 前提：日本でウケる診断の条件

MBTI・四柱推命・動物占い・骨格診断・パーソナルカラーなど、日本で流行った診断の共通点:

1. **結果がひと言で言える**（「ENFPです」「骨格ウェーブです」）
2. **タイプ数がほどよい**（4〜16個。多すぎると覚えられない）
3. **自己紹介・会話のネタになる**（「〇〇タイプっぽいよね」が言える）
4. **相性が見られる**（恋愛・友人・職場）→ 日本人は特に相性が好き
5. **キャラ化・ビジュアル化しやすい**（画像でシェアしやすい）
6. **実生活の行動につながる**（服・メイク・仕事の選び方）→ ここが収益化の入口

## 輸入候補（おすすめ順）

### 1. クロノタイプ診断（ライオン / クマ / オオカミ / イルカ）★★★
- **出どころ**: アメリカ。睡眠専門医マイケル・ブレウス博士の本『The Power of When』
- **中身**: 朝型・夜型などの体内時計を4種類の動物で分類。「何時に仕事・運動・勉強すると効率がいいか」がわかる
- **日本でウケそうな理由**: 「動物占い」の実績があるので**動物タイプ**は鉄板。睡眠・生産性・朝活ブームとも合う
- **収益化と相性がいい**: 睡眠グッズ、サプリ、枕、アイマスクなどアフィリエイトにつなげやすい
- **注意**: 本の名称や質問項目をそのまま使わず、自作の質問と独自の動物名・キャラにする

### 2. 愛着スタイル / 愛の言語（ラブランゲージ）★★★
- **出どころ**: アメリカのTikTok・恋愛系SNSで定番
  - 愛着スタイル: 安定型 / 不安型 / 回避型 / 恐れ・回避型（4タイプ）
  - 愛の言語: 言葉 / 時間 / 贈り物 / 行動 / スキンシップ（5タイプ）
- **日本でウケそうな理由**: 恋愛・相性ネタは日本で最強ジャンル。「彼氏が回避型でさ…」と会話ネタになる。カップル・友人同士で**2人で診断して相性を出す**仕組みにすると拡散しやすい
- **注意**: 「Love Languages」は商標なので、独自の名前（例：「愛され方タイプ」）に置き換える。愛着スタイルは心理学の一般概念なので使いやすいが、医療的な断定は避ける

### 3. キッベ診断（Kibbe Body Types）★★☆
- **出どころ**: アメリカのファッション系TikTokで大流行
- **中身**: 体の骨格・ライン・顔立ちから13タイプに分類し、似合う服を提案
- **日本でウケそうな理由**: 日本の「骨格診断（ストレート/ウェーブ/ナチュラル）」が既に大ヒットしているので、その**上位版・詳細版**として打ち出せる（「骨格診断の次」）
- **収益化**: 洋服・アクセのアフィリエイト、有料の個別診断、診断士養成講座
- **注意**: 13タイプは日本人には多いので、6〜8タイプくらいに整理し直すと良い

### 4. ソシオニクス（16タイプの相性理論）★★☆
- **出どころ**: ロシア・東欧で人気
- **中身**: MBTIと似た16タイプだが、**タイプ同士の関係性（相性16パターン）**の理論が充実している
- **日本でウケそうな理由**: すでにMBTIを知っている人が多いので説明コストが低い。「MBTIの相性版」として売れる
- **注意**: 理論が難しいので、相性結果だけを分かりやすくキャラ化する

### 5. アーユルヴェーダ体質診断（ヴァータ / ピッタ / カパ）★★☆
- **出どころ**: インド伝統医学。欧米のウェルネス業界で定番
- **日本でウケそうな理由**: 3タイプでシンプル。美容・食事・ヨガとつなげやすい。女性向けウェルネス層に刺さる
- **収益化**: お茶、スキンケア、食品、ヨガ講座などに直結
- **注意**: 「病気が治る」などの表現は薬機法に引っかかるのでNG

### 6. エニアグラム ★☆☆
- **出どころ**: アメリカ・韓国で人気（韓国ではMBTIの次に流行）
- **中身**: 9タイプ＋ウイング。「なぜそう行動するか（動機）」に着目
- **日本の状況**: 学会や本はあるが、一般層のSNSシェアはまだ少ない
- **注意**: 9タイプ×ウイングは少し複雑。チームビルディング等の法人向けと相性が良い

### （参考）韓国発のトレンドはすぐ日本に来る
韓国ではMBTIの後も、ホルモンタイプ（テト/エゲン）のような**SNSで一気に流行る診断**が次々出ている。韓国のトレンドを定点観測して、日本向けにローカライズするのが一番速い輸入ルート。

## 収益化の方法

### 基本の流れ（ファネル）

```
無料診断（Web or LINE）
   ↓ 結果画像をSNSでシェア → 新しい人が来る（拡散ループ）
LINE登録で「詳しい結果」「相性診断」を受け取れる
   ↓
ステップ配信でタイプ別のお役立ち情報
   ↓
有料商品へ
```

### 収益源

| 収益源 | 内容 | 単価の目安 | 向いている診断 |
|---|---|---|---|
| **広告** | 診断サイトにAdSense等 | 低い（大量のPVが必要） | 全部 |
| **有料詳細レポート** | 無料は結果だけ、有料で詳しい解説PDF | 500〜2,000円 | 全部 |
| **有料相性診断** | 2人の相性を詳しく | 500〜3,000円 | 愛着/ラブランゲージ/ソシオニクス |
| **アフィリエイト** | タイプ別のおすすめ商品 | 商品による | クロノタイプ/キッベ/アーユルヴェーダ |
| **個別セッション** | オンラインで1対1の診断・相談 | 5,000〜30,000円 | キッベ/エニアグラム |
| **診断士養成講座（資格）** | 「〇〇診断アナリスト」講座 | 10〜30万円 | キッベ/エニアグラム/アーユルヴェーダ |
| **法人研修** | チームビルディング研修 | 10万円〜/回 | エニアグラム/ソシオニクス |
| **グッズ** | タイプ別キャラのステッカー・アクキー | 1,000〜3,000円 | キャラ化したもの全部 |

### 特に日本で強いポイント
- **LINEで診断を完結させる**: 日本はLINE公式アカウント経由が圧倒的に強い。診断→結果配信→商品案内までLINE内でできる（UTAGEのLINE配信・ファネル機能で組める）
- **資格ビジネス**: 日本人は「資格」が好き。骨格診断・パーソナルカラーも「診断士講座」で大きく稼いでいる。新しい診断を最初に日本で体系化した人が講座を売れる（先行者利益）
- **キャラクター化**: 16タイプにかわいいキャラを付けると、シェア率もグッズ化も一気に上がる

## 始めるなら（おすすめプラン）

**第1候補：クロノタイプ（動物タイプ）× 睡眠・生産性**
- 理由: 動物タイプは日本で実績あり / 説明が簡単 / アフィリエイトにすぐつながる / 恋愛系より炎上リスクが低い

**第2候補：愛着スタイル・愛され方タイプ × 相性診断**
- 理由: 拡散力が一番強い / 有料相性診断が売りやすい

### 最小限のステップ
1. 質問10〜15問の診断を自作（既存の質問文をコピーしない）
2. タイプごとにキャラクターと結果画像（SNSで映える縦長画像）を作る
3. 診断ページ or LINEで公開、結果画像に「#〇〇診断」を入れてシェアしてもらう
4. TikTok/Instagramで「〇〇タイプあるある」動画を投稿して集客
5. 反応が良ければ、有料相性診断 → 個別セッション → 講座の順に商品を増やす

## 気をつけること（法律・権利）
- **商標・著作権**: MBTI、Love Languages、ヒューマンデザインなどは商標あり。名前や質問文をそのまま使わず、自分のオリジナル診断として作る
- **薬機法**: 体質・睡眠系で「治る」「改善する」などの効果をうたわない
- **特定商取引法**: 有料商品を売るなら特商法の表記が必要
- **不安をあおる売り方はNG**: 「このままだと不幸になる」系は消費者契約法上のトラブルや炎上の原因になる
- **個人情報**: 生年月日・恋愛情報を集めるならプライバシーポリシーを用意する
