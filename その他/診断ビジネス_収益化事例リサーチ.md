# 有名な診断はどうやって稼いでいるか（リサーチ）

調査日: 2026-10-27
関連ノート: [診断コンテンツ_輸入アイデアと収益化.md](./診断コンテンツ_輸入アイデアと収益化.md)

## 結論（先に）
有名な診断は、**どこもサイト広告ではほとんど稼いでいない。**
稼ぎ方は大きく分けて4つ。

1. **無料で診断 → 詳しい版を有料で売る**（16Personalities）
2. **資格・講座・ライセンスを売る**（MBTI本家、動物占い＝個性心理學）
3. **本・メディア・キャラクター展開**（動物占い）
4. **企業から依頼されて診断を作る**（診断の受託制作・成果報酬）

広告は「人を集めた結果、ついでに入るお金」程度。**本当のお金は「診断を作った人・体系化した人」という立場から生まれている。**

---

## 1. 16Personalities（MBTI風の無料診断サイト）

| 項目 | 内容 |
|---|---|
| 運営 | NERIS Analytics Limited（イギリス） |
| 規模 | 累計の受検数は2億回以上とも、7.99億回とも言われる（第三者の推計で数字にばらつきあり） |
| 無料部分 | 診断と基本的なタイプ解説は無料 |
| 有料① 個人向け | 詳しいレポート（仕事・恋愛・成長など）が **約29ドル（一回払い）** |
| 有料② チーム向け | 会社のチーム向け機能を **月額・年額のサブスク** で提供（人数で料金が変わる） |
| 有料③ プロ向け | コーチやカウンセラーが顧客に使う **レポートのクレジット販売** |

**ポイント**
- 「診断は全部無料、結果の一部も無料」で圧倒的な人数を集め、ごく一部の人に有料版を売るモデル
- 2億人のうち1%が29ドル払うだけで、200万人×約4,000円＝約80億円規模になる計算（あくまで考え方の例）
- 個人向け → 会社向け → プロ向け と、**同じ診断を3つの客層に売っている**

## 2. MBTI本家（The Myers-Briggs Company）

| 項目 | 内容 |
|---|---|
| 正体 | 16Personalitiesとは別物。MBTIは本家の会社の登録商標 |
| 売っているもの | ①正式な検査（1回ごとに有料） ②**MBTI認定資格** ③企業研修 |
| 認定資格の値段 | だいたい **1,700〜4,500ドル（約25〜65万円）** ※会場や形式で違う |
| 認定後も課金 | 資格を取った人が顧客に検査をするたびに、**1回ごとにレポート代を払う** |
| 売上 | 非公開。年間2,000万ドル以上という推計はあるが、裏付けなし |

**ポイント**
- 一般の人ではなく、**「MBTIを使って仕事をしたい人」（コーチ・人事・研修講師）に売っている**
- 資格を取った人が増えるほど、レポート代も入り続ける＝**ずっとお金が入る仕組み**

## 3. 動物占い（日本）

| 項目 | 内容 |
|---|---|
| 歴史 | 1997年ごろ誕生、1999〜2000年ごろに大ブーム（小学館『人間まるわかりの動物占い』1999年など） |
| ベースの理論 | 四柱推命を、わかりやすい動物キャラにしたもの。運営元の一つが「個性心理學研究所」（所長: 弦本將裕氏）で、「動物キャラナビ」という名前で展開 |
| 本 | シリーズ累計 **500万部突破**（販売元の表示） |
| 今の展開 | 12動物 → 大人向けに **60タイプ** に拡張、アプリ、雑誌・Webメディアでの掲載 |

**個性心理學研究所の収益モデル（公式サイトより）**

| 商品 | 値段 |
|---|---|
| 認定講師の講座 | **22万円**（税込）＋合格後に年間登録料5,500円 |
| 支局（地方の代理店）の契約 | **300万円＋税**。契約すると、その地域で資格講座を開く権利がもらえる |

**ポイント**
- ブーム自体は25年前だが、**講師資格と支局制度で今も稼ぎ続けている**
- 「講師になった人が、さらに次の受講生を集めてくれる」ので、本部が集客しなくても広がる
- 本・テレビ・雑誌で知名度を作り → 資格で稼ぐ、という流れ

## 4. 企業向けに診断を作る（受託・成果報酬）

- 企業は「診断」を**マーケティングの道具**として使いたがっている
  - 例: 「デュエマ文明診断」は公開初日に11万件以上が利用、シェア2万件
  - 例: 「明日カノ診断」は100万回以上
  - 例: よーじやの診断でECサイトへの流入が3倍に
- ある会社は、企業ごとに診断アプリを作り、**そのアプリから企業サイトに人を送った数・売れた数に応じて報酬をもらう**（初期費用なし）
  - 例の「結婚相手相性診断」アプリは8万ダウンロード、1人あたり5回ほど診断
  - 不動産・化粧品・保険など、**1人のお客さんが高いお金を払う業界**ほど報酬が大きい

## 個人が真似するなら（段階ごと）

| 段階 | やること | 参考にする例 |
|---|---|---|
| ① まず人を集める | 無料診断＋シェア。サイト広告とアフィリエイトで少し稼ぐ | 16Personalitiesの無料部分 |
| ② 少額の有料版 | 詳しいレポート・相性診断を数百〜数千円で（note / BOOTH / Stripeで販売） | 16Personalitiesの約29ドルの有料版 |
| ③ 実績で企業から仕事 | 「〇万人がやった診断を作った人」として、企業の診断を作る仕事を受ける | 企業向けの受託・成果報酬 |
| ④ 体系化して資格化 | 診断を体系化して、講師講座・認定制度を作る | MBTI認定、個性心理學の講師講座 |

**大事なこと**
- 広告だけでは、16Personalities並みの人数がいないと大きくは稼げない
- 稼いでいる人は **「自分の診断（オリジナル）」を持っている**。他人の診断を真似しただけだと、②〜④ができない（商標の問題もある）
- なので「何の診断にするか」より、**オリジナルの名前・キャラ・タイプ体系を持つこと**が、収益化の一番の土台になる
