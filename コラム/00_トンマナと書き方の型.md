# コラムのトンマナと書き方の型

骨格はジェーン・スー、問いの立て方はキャリー・ブラッドショー、社会への広げ方は三宅香帆から借りる。

## トンマナ

| 項目 | ルール |
|---|---|
| 一人称・文末 | 「私」。常体が基本で、ときどき「〜なのだ」「〜なあ」 |
| 書き出し | 場面で始める。説明から入らない |
| 問い | 中盤で一度だけ、キャリー式の問いを立てる（例：「頑張りすぎ、とは誰が決めるのだろう」） |
| 自虐 | 括弧で一言添える。自分を下げすぎない |
| 比喩 | 体や日用品のように、手で触れられるもので例える |
| 広げ方 | 個人の話から世代・時代の話へ。事実を一つだけ入れて補強する |
| 距離感 | 相手の世代を下げない。毒は世の中の「物差し」に向け、人には向けない |
| 結び | 正論で締めない。仮の答えか、次の行動で終わる |
| NG | 自慢に聞こえる言い方、説教、「〜すべき」 |

## 参考にした3人の特徴

- **ジェーン・スー**：常体に「〜なのだなあ」の脱力。括弧の自虐。体や物の比喩。硬い漢語と口語を混ぜる。エピソード → 自己分析 → 一般化の言い切り。
- **キャリー・ブラッドショー**：毎回一つの問い（*I couldn't help but wonder...*）を立て、出来事を全部その材料にする。ウィットと弱さを同時に見せる。答えを出し切らずに着地する。
- **三宅香帆**：身近な場面 → 言葉の定義 → 社会の変化。書名や調査などの事実で補強する。自分へのツッコミ、読者への語りかけ。

## 書く流れ

1. モヤッとした・笑った・引っかかった出来事を一行メモする
2. インタビューで掘る（場面、そのときの気持ち、昔の自分ならどうだったか、格好悪い部分）
3. 芯を一文で決める（例：「心配を、心配のまま受け取れるようになった」）
4. 骨組みを作る：場面 → 一言 → 問い → 私の物差し → 相手の物差し → 昔の私 → 今の私 → 仮の答え
5. 比喩を一つ通す。最後に冒頭の場面へ戻してオチにする（例：二日酔いしない酒豪のお母さん）
6. 自慢に聞こえないか、相手を下げていないかを読み直す
