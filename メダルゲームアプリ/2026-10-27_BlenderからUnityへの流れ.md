# Blender で作った3DモデルをUnityに入れる流れ

**日付:** 2026-10-27

## 結論
できる。Blender（無料）で作って Unity に入れるのは、個人ゲーム制作のごく一般的なやり方。

## 基本の流れ
1. Blender でモデルを作る（形 → 色・テクスチャ → 必要なら骨組みと動き）
2. FBX 形式で書き出す
3. Unity のプロジェクトのフォルダに入れる（ドラッグ＆ドロップで読み込まれる）
4. Unity 側で見た目（マテリアル）と当たり判定を設定する

※ .blend ファイルをそのまま Unity に入れることもできるが、PCに Blender が入っていないと開けないなど扱いにくい。FBX で書き出すのがおすすめ。

## つまずきやすいポイント
| ポイント | 内容 | 対策 |
|---|---|---|
| 向きと大きさ | Blender と Unity で「上」の向き（Z と Y）が違い、倒れたり大きさがずれたりする | 書き出し前に「トランスフォームを適用」。FBX書き出しの設定で向きを合わせる |
| 見た目（マテリアル） | Blender で作った質感の設定はそのままは移らない。画像（テクスチャ）は移る | 色や模様は画像にしておき、Unity 側で質感を付け直す |
| 動き（アニメーション） | 骨組み（アーマチュア）と動きは FBX に含めて持っていける | 動きごとに名前を付けて書き出す |
| 重さ | スマホは処理能力が限られる | ポリゴン数を抑えたローポリにする。丸っこい職人キャラはローポリと相性が良い |
| 当たり判定 | 見た目の形をそのまま判定に使うと重い | メダルは円柱、台は箱など、Unity の単純な形で判定を作る |

## 見た目の雰囲気づくり
- アニメ・絵本のような柔らかい見た目にするなら「トゥーン調」の表示方法（シェーダー）を使う
- Unity 公式の無料トゥーンシェーダーもある

## 作る順番のおすすめ
1. **最初は Blender を使わない。** メダル（円柱）や台（箱）は Unity の基本図形だけで作り、押し出しの手触りを確かめる
2. 動きが楽しいと確認できたら、Blender で塔の段やメダルの見た目を作り込む
3. 最後にキャラクター（形 → 骨組み → 動き）。いちばん難しいので後回し
