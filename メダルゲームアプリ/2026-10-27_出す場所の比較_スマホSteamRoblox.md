# 出す場所の比較：スマホアプリ／Steam／Roblox

**日付:** 2026-10-27
**前提:** 手持ちのPCは Windows。ゲーム制作は初めて。3Dで作りたい。

## 比較
| | スマホ（Android/iPhone） | Steam（PC） | Roblox |
|---|---|---|---|
| 作るツール | Unity | Unity | Roblox Studio（専用。Unityとは別物） |
| 使う言語 | C# | C# | Luau |
| Windowsだけで作れるか | Androidは可。iPhoneはMacが必要 | 可（作ったPCでそのまま確認できる） | 可 |
| 出すための費用 | Google 約4,000円＋Apple 年1万5千円前後 | 1作品100ドル（約1万5千円前後）。売上1,000ドルを超えると返金される | 0円 |
| 主な稼ぎ方 | 広告・アプリ内課金 | 買い切り（例: 500〜1,500円） | ゲーム内通貨（Robux）での課金 |
| 手数料・取り分 | ストアが15〜30％ | Steamが30％ | 換金レートの関係で、手元に残るのはかなり少ない |
| 遊ぶ人 | 幅広い | PCゲーム好き。放置系の人気ジャンルあり | 子ども・10代が中心 |
| ギャンブル風要素 | 年齢区分が上がる | お金を賭けなければ基本OK | 子どもが多く規約が厳しめ。要確認 |
| 3Dの見栄え | 中 | 高 | 低め（独特の見た目） |

## それぞれの特徴
- **Steam**
  - 買い切りなら課金・広告の設計が不要 → 規制の心配がさらに減る
  - Windows PCだけで「作る → 試す → 出す」まで完結
  - 「画面の端に置いておく放置ゲーム（デスクトップ常駐型）」が人気ジャンル。
    作業中に画面の下でメダル台が動いている、という形にできる
  - 売るには「ウィッシュリスト」を集める宣伝が大事
- **Roblox**
  - 無料で出せて、最初から遊ぶ人が大勢いる
  - 友達と同じ台で遊ぶ、などのマルチプレイが作りやすい
  - ただしUnityとは道具も言語も別。途中で乗り換えると作り直しになる
  - 大量のメダルの物理演算は重くなりやすい
- **スマホ**
  - 遊ぶ人は一番多いが、無料アプリが多く目立ちにくい
  - 稼ぐには広告・課金の設計が必要

## おすすめ
**Unity で作って、まず Steam（Windows版）に出す。** 余裕があれば後からスマホ版へ。
- Windows PCだけで完結する
- 同じUnityの中身を後からAndroid/iPhoneにも持っていける
- 買い切りにすれば、課金・規制の悩みがほぼなくなる
- 放置要素は「お金を払わせる仕組み」ではなく「画面に置いておく楽しみ」として自然に使える

Roblox は「友達と一緒に遊ぶメダルゲーム」にしたい場合の選択肢。その場合は最初から Roblox Studio で作ると決める必要がある。
