# メダルゲームアプリ

放置要素でメダルを稼ぎ、メダルゲームで遊ぶスマホアプリの企画フォルダ。
主役はあくまでメダルゲーム。放置は補給係。

## 決まっている方針
- 課金でメダルを買えない（直接も間接も）
- メダルや景品を換金・譲渡できない
- 放置で溜まるのはメダルそのもの。タンク方式で上限あり
- 放置の強化はメダルゲームの成果でのみ行う
- プッシャー型。ミニゲームで塔が積み上がり、JPチャレンジで崩して排出（バベルの塔モチーフ）
