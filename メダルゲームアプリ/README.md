# メダルゲームアプリ

放置要素でメダルを稼ぎ、メダルゲームで遊ぶスマホアプリの企画フォルダ。
主役はあくまでメダルゲーム。放置は補給係。

## 決まっている方針
- 課金でメダルを買えない（直接も間接も）
- メダルや景品を換金・譲渡できない
- 放置で溜まるのはメダルそのもの。タンク方式で上限あり
- 放置の強化はメダルゲームの成果でのみ行う
- プッシャー型。ミニゲームで塔が積み上がり、JPチャレンジで崩して排出（バベルの塔モチーフ）
- ミニゲームはフィールドのカラーボールを落とすと発生。色ごとに違うミニゲーム
- 3Dで作る（Unity が第一候補）。神話そのままは避け、オリジナルの世界観とキャラクターにする
- 作業用PCは Windows。出す場所はスマホ／Steam／Roblox を検討中→ いったんスマホアプリで進める（Unity）
- ビジュアルは「A 空の職人町」の職人を軸にする
